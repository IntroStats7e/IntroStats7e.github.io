# Used Civics 2025

The web site www.autotrader.com lists cars for sale. On Feb. 25, 2025 it listed many used Honda Civics for sale by owner. From those listings, we extracted the asking price ($), the mileage, and the model year (from which we computed the age of the car at the time the data were collected  Questions include how to best predict the price from mileage and age and whether any of the cars is a particularly good buy.   

The data are in `Used_Civics_2025.txt`


This dataset is sourced from: www.autotrader.com accessed on February 25, 2025 search for Honda Civics for sale by owner.
