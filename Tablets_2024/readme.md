# Tablets 2024

Are the size and battery life of smartwatches related? Best Smart Watches compares the specs of many smartwatch models. 

The data are in `Tablets_2024.txt`

The variables in this dataset are: 

Header | Description
---|--------
`Model` | 
`Video.battery.life..in.hours.` | 
`Maximum.brightness..in.cd.m2.` | 
`Resolution` | 
`Pixel.density..ppi.` | 
`Screen.size..in.inches.` | 

This dataset is sourced from: https://www.cnet.com/news/cnet-tablet-battery-life-results/
