# Shoot to Score 2016

A college hockey coach collected data from the 2016–2017 National Hockey League season. He hopes to convince his players that the number of shots taken has an effect on the number of goals scored. The data includes both offensive and defensive players.

The data are in `Shoot_to_Score_2016.txt`


This dataset is sourced from: http://www.nhl.com/stats/player?aggregate=0&gameType=2&report=skatersummary&pos=S&reportType=season&seasonFrom=20162017&seasonTo=20162017&filter=gamesPlayed,gte,1&sort=gamesPlayed referenced January 16, 2017
