# Streams

As part of the course work, a class at an upstate NY college collects data on streams each year. Students record a number of biological, chemical, and physical variables, including the stream name, the substrate of the stream (limestone (L), shale (S), or mixed (M)), the pH, the temperature (C), and the BCI, a measure of biological diversity.

The data are in `Streams.txt`
